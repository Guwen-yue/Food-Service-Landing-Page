## ✨ 项目简介
> 本文配套的**餐饮外卖产品着陆页**示例工程，完整实现了 Foodiez App 的官网首屏效果，包含响应式布局、品牌视觉与下载引导模块，是纯前端静态页面开发的实战案例。

## 🎯 功能/效果预览
- 品牌 Logo 与导航栏
- 核心标语与产品价值描述
- App Store / Google Play 下载按钮
- 产品核心数据展示（评分、配送时效、合作餐厅）
- 移动端 App 界面预览
